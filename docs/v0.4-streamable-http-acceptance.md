## C5/C6

C5 原生 Beeline 全量对账与 C6 性能 SLA/排名按任务书保持 `WAIVED / OUT OF
SCOPE`，没有为它们执行生产压力或全量对账。

## 可复现命令

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
& '.\.venv\Scripts\python.exe' -m pytest -q
& '.\.venv\Scripts\python.exe' -m compileall -q src tests
git diff --check
```

```bash
carbon-lens serve --transport streamable-http --host 127.0.0.1 --port 8765 --path /mcp
```

远程部署时应设置 `CARBON_LENS_HTTP_ACCESS_TOKEN`，并用
`--public-base-url` 生成可信下载 URL；不要在命令记录、TOML 或日志中写 token。
